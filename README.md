# OpenSociometry 0.1.2

Локальная программа для социометрии

OpenSociometry — программа для проведения и обработки социометрии по Морено: ввод выборов участников,
расчёт индивидуальных и групповых индексов, социоматрица и интерактивные социограммы.
Работает полностью на вашем компьютере, в браузере. Интернет не нужен, данные никуда не отправляются.

## Что нужно

Для готовых пакетов со страницы релиза ничего устанавливать не нужно. Для запуска исходного кода нужны **Python 3.9 или новее** и зависимости: `python -m pip install -r requirements.txt`.

## Установка и запуск на Windows

1. Скачайте `OpenSociometry-v0.1.2-windows-x64.zip` со страницы релиза и распакуйте в любую папку, например в «Документы».
   Для архива с исходным кодом сначала установите Python с https://www.python.org/downloads/ и отметьте «Add Python to PATH».
2. Дважды щёлкните файл **`start.bat`**. Откроется чёрное окно и браузер со страницей программы.
3. Пока работаете, не закрывайте чёрное окно. Закрыли окно — программа остановилась.

## Установка и запуск на macOS

1. Скачайте со страницы релиза архив `OpenSociometry-v0.1.2-macos-arm64.zip` для Mac с Apple Silicon или `OpenSociometry-v0.1.2-macos-intel.zip` для Mac с Intel.
   Для архива с исходным кодом сначала установите Python с https://www.python.org/downloads/.
2. Распакуйте архив в любую папку.
3. Дважды щёлкните **`start.command`**. Если macOS пишет, что файл от неизвестного разработчика, щёлкните по нему
   правой кнопкой → «Открыть» → «Открыть». Это нужно только в первый раз.
4. Браузер откроется сам. Пока работаете, не закрывайте окно Терминала.

**Если появилось «нет соответствующих прав доступа».** Так бывает, когда при скачивании или распаковке файл теряет
разрешение на запуск. Откройте «Терминал», напечатайте `bash ` (с пробелом в конце), перетащите файл `start.command`
мышкой в окно Терминала и нажмите Enter. Программа запустится.
Чтобы двойной щелчок снова работал, один раз выполните в Терминале `chmod +x ` (с пробелом), перетащите туда `start.command` и нажмите Enter.

Если браузер не открылся, найдите адрес в окне Терминала/консоли (обычно **http://127.0.0.1:8765**). Если порт занят старой копией, новая версия сама выберет следующий свободный порт и покажет его адрес.

## Где хранятся данные

Всё сохраняется автоматически в файл `data/sociometry.db` внутри папки программы.

* Чтобы перенести все социометрии на другой компьютер, скопируйте этот файл при закрытой программе.
* Для одной социометрии есть кнопка «Скачать резервную копию (.json)», а на главной — «Восстановить из резервной копии». Копия включает имена, выборы и фотографии, поэтому храните её в подходящем вам месте.
* При обновлении программы просто перенесите папку `data` в новую версию.

## Возможности

* Несколько социометрий (групп), в каждой — любое число участников и критериев (вопросов).
* Положительные и отрицательные выборы, лимит числа выборов с подсветкой превышения.
* Перцептивные выборы («кто, по-вашему, выбрал вас») и расчёт точности ожиданий.
* Загрузка списка участников или готовой матрицы выборов из Excel (.xls, .xlsx) и CSV. Образцы файлов можно скачать при создании социометрии.
* Поиск и копирование социометрий; отметки о заполненных анкетах, фотографии участников и сохранение раскладки графов.
* Индивидуальные показатели: статус (+, −, сводный), эмоциональная экспансивность, Куд, место в группе, статусная категория
  (звезда, предпочитаемый, принятый, изолированный, отвергнутый).
* Групповые индексы: сплочённость, конфликтность, доля взаимных выборов, групповая экспансивность, напряжённость,
  КБВ, индекс изолированности.
* Общий и личные отчёты; списки взаимных положительных, отрицательных и парадоксальных выборов.
* Социограмма с силовой раскладкой (перетаскивание узлов, масштаб колесом, фильтры «+», «−», «только взаимные»),
  социограмма-мишень и социоматрица. Схемы можно скачать в SVG.
* Плоская диаграмма статусов: переключение между локальным интерактивным Plotly и Matplotlib, просмотр участников по категориям. Экспорт Plotly в SVG и PNG 2400 × 1800 с метаданными 300 DPI; экспорт Matplotlib в PNG 300 DPI.
* Выгрузка результатов в CSV (открывается в Excel) и печать / сохранение в PDF через браузер.
* Демо-пример с вымышленными данными.

Формулы описаны на странице «Справка» внутри программы.

## Настройки для продвинутых

* Другой порт: переменная окружения `SOCIOMETRY_PORT` (по умолчанию 8765).
* Другой файл базы: переменная `SOCIOMETRY_DB`.
* Запуск без автоматического открытия браузера: `python app.py --no-browser`.
